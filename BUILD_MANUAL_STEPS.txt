Omnix 3.0 manual Windows build
==============================

Use Python 3.11 or newer. Run these commands from the repository root in
PowerShell (the same flow works in Command Prompt with the activation command
adjusted).

1. Create and activate a virtual environment:

       py -3.11 -m venv .venv
       .venv\Scripts\Activate.ps1

2. Install the packaged application and build tools:

       python -m pip install --upgrade pip
       python -m pip install -e ".[build]"

3. Build the unsigned onedir bundle from the maintained spec:

       python -m PyInstaller GamingAIAssistant.spec --clean --noconfirm

The bundle is written to `dist\GamingAIAssistant\`. Launch
`GamingAIAssistant.exe` from that directory to smoke-test the build. The
specification packages `omnix` from `src/omnix`; no WebEngine or legacy flat
module hidden-import list is required.

For a debug build, use `GamingAIAssistant_debug.spec` instead. Release builds
are unsigned; apply the project's code-signing process before distribution.

Troubleshooting:

- If `py` is unavailable, install Python from https://www.python.org/downloads/
  and enable “Add Python to PATH”.
- If Qt cannot initialize in CI, set `QT_QPA_PLATFORM=offscreen`.
- If dependencies are stale, recreate `.venv` and repeat step 2; dependency
  versions are defined in `pyproject.toml` and locked in `uv.lock`.
